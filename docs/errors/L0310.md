# L0310: nesting too deep

Expressions, types or blocks are nested more than 64 levels deep, or text is nested more than 8 levels deep through interpolations.

## Example

```lymra
constant deep = ((((((((((((((((((((((((((((((((((((((((((((((((((((((((((((((((((((((1))))))))))))))))))))))))))))))))))))))))))))))))))))))))))))))))))))))
```

## Why

The limit keeps the compiler's own memory use bounded, so no input, however strange, can crash it. Code written by a person never comes close: beyond a handful of levels, nesting is already unreadable.

## Fix

Split the code up. Give the inner part a name with a constant, or move it into its own function.
