# L0110: code after a multiline comment

A multiline comment that spans several lines is followed by code on the line where it closes.

## Example

```lymra
function main()
    #[ This comment
       spans two lines. ]# print("easy to miss")
```

## Why

Code after the closing `]#` sits where a reader does not look for it. Its indentation would also have to be measured from inside the comment, which makes no sense.

A comment that opens and closes on the same line can sit anywhere, including before code.

## Fix

Put the code on its own line.

```lymra
function main()
    #[ This comment
       spans two lines. ]#
    print("easy to see")
```
