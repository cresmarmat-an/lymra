# L0405: operator used on the wrong type

An operator is used on a type it does not work on.

| Operators | Work on |
|---|---|
| `+` `-` `*` `/` `%` | integers of the same type |
| `-` in front of a value | signed integers |
| `<` `<=` `>` `>=` | integers of the same type |
| `==` `!=` | two values of the same type |
| `and` `or` `not` | `boolean` values |

## Example

```lymra
function main()
    constant string first = "Hello, "
    constant string second = "world"
    constant joined = first + second
    print(joined)
```

## Why

Each operator means one thing. `+` adds numbers; it does not also join text, so `a + b` never needs its types checked to know what it does. A `boolean` has no order, so it cannot be compared with `<`. An unsigned value has no negative, so it cannot be negated.

## Fix

Use the operation meant for the type. Text is put together with interpolation:

```lymra
function main()
    constant string first = "Hello, "
    constant string second = "world"
    print("{first}{second}")
```
