# L0706: pool of values without one fixed size

A pool keeps each value in a slot, and every slot has the same size, so a pool only holds values whose size is fixed: numbers, booleans, handles, arrays, and types and choices made of them. Text can have any length and a list grows, so a pool can't hold them, or a type that holds one.

## Example

```lymra
type Creature
    string name
    integer32 health

function main()
    variable pool[Creature] creatures = pool()
    constant first = insert(variable creatures, Creature(name = "Kero", health = 3))
    print("{creatures[first].health}")
```

## Why

`remove` frees a slot, and the next `insert` puts its value there. That works because every value fits every slot. A name can be one byte or a million, so a slot sized for one name would not fit the next, and moving the values around to make room would leave every handle naming the wrong slot.

## Fix

Keep the text in a list, and store its position in the value:

```lymra
type Creature
    integer64 name
    integer32 health

function main()
    variable list[string] names = list()
    push(variable names, "Kero")
    variable pool[Creature] creatures = pool()
    constant first = insert(variable creatures, Creature(name = 0, health = 3))
    print("{names[creatures[first].name]} {creatures[first].health}")
```
