# L0101: directive after the top of the file

A `#!` line appeared after the first declaration, or inside a function.

## Example

```lymra
function main()
    print("hello")

#!optimize speed
```

## Why

A directive is an instruction about the whole file. If one could appear anywhere, you would have to read the entire file to know how it is compiled. At the top, one glance is enough.

## Fix

Move the line above the first declaration. Comments and blank lines may come before it.

```lymra
#!optimize speed

function main()
    print("hello")
```
