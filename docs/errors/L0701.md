# L0701: view outlives what it shows

A view shows elements that something else keeps: a binding, a parameter, or text in the program. It cannot last longer than that. Here a function returns a view of its own list, which is freed when the function returns.

## Example

```lymra
function first_three() returns view[integer64]
    variable list[integer64] numbers = list()
    for number in range(0, 5)
        push(variable numbers, number)
    return slice(numbers, 0, 3)

function main()
    constant three = first_three()
    print("{length(three)}")
```

## Why

A view is where some elements start and how many there are. It owns none of them. When `first_three` returns, its list `numbers` is freed, so the view it hands back would point at memory that the next list built there takes over. In C that is a dangling pointer, and reading it gives whatever was written there since. Rust rejects it too, but asks you to write lifetimes on the function so it can check.

Lymra works out on its own what every view shows, its root, across the whole program: a view of a parameter shows what the caller passed, and a call that returns one shows what its arguments show. A view can't outlast its root: it can't be returned from the function that holds the root, can't be kept in a binding when it shows a value its statement frees, and can't be kept past the block that holds its root.

## Fix

Return the list itself. It moves to the caller, so nothing is freed under it:

```lymra
function first_three() returns list[integer64]
    variable list[integer64] numbers = list()
    for number in range(0, 3)
        push(variable numbers, number)
    return numbers

function main()
    constant three = first_three()
    print("{length(three)}")
```

Or keep the list where the view is used, and return a view of a parameter:

```lymra
function first_three(view[integer64] numbers) returns view[integer64]
    return slice(numbers, 0, 3)

function main()
    variable list[integer64] numbers = list()
    for number in range(0, 5)
        push(variable numbers, number)
    constant three = first_three(numbers)
    print("{length(three)}")
```
