# L0204: declaration without an initial value

A `variable` or `constant` is declared without `= value`.

## Example

```lymra
function main()
    variable integer64 total
    total = 10
```

## Why

Lymra has no uninitialized bindings (spec 3). If a binding could exist without a value, reading it before the first assignment would be a bug that the compiler has to chase through every path of the program. Requiring a value at the declaration makes that bug impossible to write.

## Fix

Give the binding its first value where it is declared.

```lymra
function main()
    variable integer64 total = 10
```
