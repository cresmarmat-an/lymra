# L0105: unknown directive

A `#!` line names a directive that does not exist.

The directives are `#!edition 0.1`, `#!optimize speed`, `#!optimize size`, `#!optimize debug` and `#!prove bounds`.

## Example

```lymra
#!nocheck
#!optimise speed
```

## Why

An unknown directive is an error, not a warning. A misspelled directive that was silently ignored would leave you believing the file is compiled one way when it is compiled another.

Three names are rejected on purpose:

- `#!nocheck` and `#!nonstrict` would turn safety checks off. Lymra has no switch for that, because a safety guarantee with an off switch is not a guarantee.
- `#!strict` would do nothing. Lymra is always strict.

## Fix

Fix the spelling, or remove the line. If you wanted `#!nocheck` to speed up a loop, use `#!prove bounds` instead: the compiler then has to prove that no bounds check is needed, so you get the speed and keep the safety.
