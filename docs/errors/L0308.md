# L0308: invalid assignment target

The left side of `=`, or an argument marked `variable`, is not something that can be changed.

## Example

```lymra
function main()
    area(2, 3) = 6
    add_item(variable 5, 7)
```

## Why

Only three things can be assigned to: a binding (`name`), a field (`item.field`) and an element (`items[i]`). A call or a number has no storage of its own to write into.

The same holds for an argument marked `variable`. The mark says the call may change the caller's binding, so there has to be a binding.

## Fix

Assign to a name, a field or an element. If you meant to compare two values, write `==`.

```lymra
function main()
    variable result = area(2, 3)
    result = 6
    add_item(variable numbers, 7)
```
