# L0703: value replaced while something still uses it

A list cannot be replaced while something still reads its elements: a `for` loop that goes over it, or a view of it that is used later. Replacing it frees those elements.

## Example

```lymra
function main()
    variable list[integer64] pending = list()
    push(variable pending, 1)
    for item in pending
        pending = list()
        print("{item}")
```

## Why

`for item in pending` reads one element of `pending` each time around, from where the list keeps them. `pending = list()` frees that storage at once, so the next turn would read whatever was built there afterward: memory that holds something else. C++ lets this happen and calls it undefined behavior; Java stops the program while it runs. Lymra rejects it before the program exists.

A function that gets the list with `variable` and can replace it, itself or through the functions it calls, makes the same mistake when it is called inside the loop; one that only adds to the list is fine. Changing an element, or adding one with `push`, is fine: elements never move, and the loop goes over the elements the list held when it started.

A view is the same: `constant first = slice(pending, 0, 1)` shows elements of `pending`, so `pending` cannot be replaced while `first` is still used after that point. The compiler follows where every view is used, so replacing the list after the last use of its views is fine.

So is a pool, with its handles. A new pool's slots start over at the first generation, so a handle into the old one could match a slot of the new one and read another value with no error at all. A pool can't be replaced while a handle into it is still used, or while a `for` loop goes over handles into it.

## Fix

Build the new contents in another list, and replace the old one after the loop:

```lymra
function main()
    variable list[integer64] pending = list()
    push(variable pending, 1)
    variable list[integer64] next = list()
    for item in pending
        push(variable next, item * 2)
        print("{item}")
    pending = next
    print("{length(pending)}")
```
