# L0412: `array(value)` without a type

`array(value)` builds an array with every element set to `value`. Its length is not an argument: it comes from the type of the place the array goes, such as the declared type of a binding, a parameter, or the type a function returns.

## Example

```lymra
function main()
    variable scores = array(0)
    print("{length(scores)}")
```

## Why

The length is part of an array's type, and the compiler has to know it to lay the array out on the call stack. `array(0)` alone says what goes in each element, but not how many elements there are, and Lymra never guesses one.

## Fix

Write the type of the binding, which says the length.

```lymra
function main()
    constant array[integer64, 8] scores = array(0)
    print("{length(scores)}")
```
