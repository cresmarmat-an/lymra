# L0205: `variable` outside a function

A `variable` is declared at the top level of a file. Only `constant` can be declared there.

## Example

```lymra
variable counter = 0

function main()
    counter = counter + 1
```

## Why

A top-level `variable` would be global mutable state: any function could change it, so no function could be understood on its own. It would also break the thread model, in which threads share no mutable memory.

Top-level constants are different. They are fixed at compile time and can never change.

## Fix

If the value never changes, declare it as a `constant`. If it does change, declare it inside the function that owns it and pass it to the functions that need it. A function that changes it takes it as a `variable` parameter.

```lymra
function count_up(variable integer64 counter)
    counter = counter + 1

function main()
    variable counter = 0
    count_up(variable counter)
```
