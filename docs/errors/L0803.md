# L0803: `try` without a call that can fail

`try` takes the call right after it, which has to be a call to a function declared with `fails`.

## Example

```lymra
function double(integer64 value) returns integer64
    return value * 2

function main() fails string
    print("{try double(4)}")
```

## Why

`try` says that the line can end the function early, so a reader looks for the failure it passes on. A call that cannot fail has none, and a `try` in front of it would send the reader looking for a way out that does not exist. Only calls carry results, so a `try` before anything else is a mistake too.

## Fix

Remove `try` where nothing can fail:

```lymra
function double(integer64 value) returns integer64
    return value * 2

function main()
    print("{double(4)}")
```
