# L0208: constant or parameter changed

A line changes a binding that cannot change: a `constant`, a top-level constant, a parameter, or a loop variable. Passing one with `variable` counts as changing it. The elements a view shows cannot change through the view either: a view only reads.

## Example

```lymra
function main()
    constant count = 1
    count = 2
    print("{count}")
```

## Why

`constant` is a promise that the value never changes, and both readers and the compiler rely on it. Parameters are constant too: a function can change its caller's binding only through a `variable` parameter, and only when the caller marks the argument with `variable`. A loop variable belongs to the loop, which sets it on every round. A view is a promise of the same kind: a function that takes a `view[integer64]` can read any array or list it is given, and the caller knows that nothing changes in it.

## Fix

Declare the binding with `variable` if it has to change. To change a copy of a parameter, copy it into a local `variable` first. To change the elements a view shows, change them through the array or list itself, or take that one as a `variable` parameter.

```lymra
function main()
    variable count = 1
    count = 2
    print("{count}")
```
