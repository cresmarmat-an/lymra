# L0208: constant or parameter changed

A line changes a binding that cannot change: a `constant`, a top-level constant, a parameter, or a loop variable. Passing one with `variable` counts as changing it.

## Example

```lymra
function main()
    constant count = 1
    count = 2
    print("{count}")
```

## Why

`constant` is a promise that the value never changes, and both readers and the compiler rely on it. Parameters are constant too: a function can change its caller's binding only through a `variable` parameter, and only when the caller marks the argument with `variable`. A loop variable belongs to the loop, which sets it on every round.

## Fix

Declare the binding with `variable` if it has to change. To change a copy of a parameter, copy it into a local `variable` first.

```lymra
function main()
    variable count = 1
    count = 2
    print("{count}")
```
