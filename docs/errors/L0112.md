# L0112: unknown escape sequence

A backslash in text is followed by a character that does not form an escape.

| Escape | Meaning |
|---|---|
| `\n` | line break |
| `\t` | tab |
| `\r` | carriage return |
| `\0` | the zero byte |
| `\\` | a backslash |
| `\"` | a double quote |

## Example

```lymra
constant path = "C:\Users\kero"
```

## Why

A backslash always starts an escape. If an unknown escape were kept as written, a typo such as `\N` for `\n` would silently produce the wrong text.

## Fix

To write a backslash, double it. Braces are not escaped with a backslash; they are doubled instead.

```lymra
constant path = "C:\\Users\\kero"
constant braces = "{{ and }}"
```
