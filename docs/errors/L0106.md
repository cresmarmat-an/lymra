# L0106: directive used incorrectly

The directive exists, but its arguments are wrong, or it is given twice.

## Example

```lymra
#!edition 2.0
#!optimize fast
#!optimize speed
#!optimize size
```

## Why

Each directive takes exactly one word from a fixed list:

| Directive | Accepted |
|---|---|
| `#!edition` | `0.1` |
| `#!optimize` | `speed`, `size`, `debug` |
| `#!prove` | `bounds` |

A second `#!optimize` could only contradict the first, so repeating a directive is an error.

## Fix

Use one of the accepted words, and give each directive once.

```lymra
#!edition 0.1
#!optimize speed
```
