# L0409: array type written wrong

An array type names the type of its elements and how many there are, in that order: `array[integer64, 10]`. The length is a number of at least 1. Writing brackets after another type, as in `integer64[10]`, is the same mistake.

## Example

```lymra
function main()
    variable integer64[10] scores = array(0)
    scores[0] = 7
    print("{scores[0]}")
```

## Why

Every array has a length fixed while compiling, so the compiler knows its size, keeps it on the call stack, and can check or prove every index. The element type comes first because it is what the array is: ten `integer64` values. An array of no elements could hold nothing, and C, which Lymra compiles to, has no such arrays either.

## Fix

Write `array`, then the element type and the length in brackets.

```lymra
function main()
    variable array[integer64, 10] scores = array(0)
    scores[0] = 7
    print("{scores[0]}")
```
