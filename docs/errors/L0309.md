# L0309: feature not available yet

The code uses something this compiler cannot handle yet, for one of two reasons:

- The feature is reserved for a later edition of the language, such as `external` declarations and generic functions. Their design is not settled.
- The feature belongs to edition 0.1, but the compiler has not reached the roadmap phase that implements it. The message names the phase.

| Phase | Adds |
|---|---|
| 2 | `float32` and `float64`, arrays and indexing, `type` declarations and fields, choices and `match`, comparing text, named arguments, `length`, wrapping arithmetic |
| 3 | `list`, `stack` and `view`, text built from values, `for` over lists, `with` blocks |
| 4 | Modules and `use` |
| 5 | Pools |

## Example

```lymra
external function hypot(float64 x, float64 y) returns float64

function first[Item](view[Item] items) returns Item
    return items[0]
```

## Why

Accepting code the compiler cannot check would break the promise that a program which compiles is safe. Guessing the syntax of an unsettled feature would mean breaking that code later. So the compiler stops here and says when the feature arrives.

## Fix

Write that part another way for now. A value that needs a fraction can often be counted in smaller whole units, as cents instead of dollars:

```lymra
function main()
    constant integer64 price_in_cents = 1_999
    print("{price_in_cents} cents")
```
