# L0309: feature not available in this edition

The code uses something the language reserves but edition 0.1 does not include yet.

## Example

```lymra
external function hypot(float64 x, float64 y) returns float64

function first[Item](view[Item] items) returns Item
    return items[0]
```

## Why

`external` declarations, which will call C functions, and generic functions are open design questions (spec 12, O8 and O2). Their syntax is not settled. Accepting a guess now would mean breaking that code later, so the compiler rejects them until the design is final.

## Fix

Remove the declaration for now. The roadmap in the README says which phase adds each feature.
