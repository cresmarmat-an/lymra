# L0203: declaration without `variable` or `constant`

A line has the shape of a declaration, a type and a name before `=`, but does not start with `variable` or `constant`.

## Example

```lymra
function main()
    string name = "Kero"
```

## Why

Every declaration starts with one of the two keywords (spec 3). That gives three guarantees:

- A line without a keyword is always an assignment to a binding that already exists. A typo in a name can never create a new binding by accident.
- You see at the declaration whether the value can change.
- The grammar stays simple. Without the keyword, `list[integer32] x = y` could be a declaration or an indexing expression, and the parser could not tell until it had read past the bracket.

## Fix

Start the line with `constant` if the value never changes, or `variable` if it does.

```lymra
function main()
    constant string name = "Kero"
```
