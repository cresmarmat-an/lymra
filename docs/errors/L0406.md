# L0406: division by zero

A division or remainder has a divisor that is always zero.

## Example

```lymra
function main()
    constant integer64 total = 10
    print("{total / 0}")
```

## Why

Division by zero has no result. When the compiler can see that a divisor is always zero, the line can never succeed, so it is rejected before the program runs. A divisor known only at run time is checked when the program runs, and a zero stops the program with a runtime error.

## Fix

Divide by a value that is not zero, and check a divisor that comes from elsewhere before dividing.

```lymra
function share(integer64 total, integer64 parts) returns integer64
    if parts == 0
        return 0
    return total / parts

function main()
    print("{share(10, 0)}")
```
