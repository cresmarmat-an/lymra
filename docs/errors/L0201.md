# L0201: assignment to an undeclared name

A line assigns to a name that no `variable` or `constant` declares.

## Example

```lymra
function main()
    total = 10
    print("{total}")
```

## Why

A line without `variable` or `constant` is always an assignment to a binding that already exists. If an assignment could also create a binding, a misspelled name would quietly create a second one, and the change you meant would never happen.

When a declared name is spelled almost the same, the error suggests it.

## Fix

Declare the binding with `constant`, or with `variable` if it changes later.

```lymra
function main()
    constant total = 10
    print("{total}")
```
