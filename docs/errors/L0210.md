# L0210: top-level constant not known at compile time

A top-level constant is computed from something that only exists when the program runs, such as a function call, or it depends on itself.

## Example

```lymra
function compute() returns integer64
    return 6 * 7

constant answer = compute()

function main()
    print("{answer}")
```

## Why

The compiler computes every top-level constant and stores the result in the program. Constants exist before `main` starts, so the order in which a program starts up is never in question. A function call only happens while the program runs, so it cannot give a constant its value.

A constant built from literals, operators and other top-level constants is computed by the compiler. If a constant leads back to itself, as in `constant first = second` and `constant second = first`, it has no value at all.

## Fix

Write the value from literals and other constants, or compute it inside a function.

```lymra
constant answer = 6 * 7

function main()
    print("{answer}")
```
