# L0109: multiline comment is never closed

A comment opened with `#[` has no matching `]#` before the end of the file.

## Example

```lymra
#[ This comment never ends.

function main()
    print("this is all still comment")
```

## Why

Multiline comments nest: every `#[` inside one needs its own `]#`. That lets you comment out code that already contains a comment. It also means a stray `#[` inside a comment keeps it open.

A single-line comment that begins with a square bracket, such as `#[1] see below`, is read as the start of a multiline comment.

## Fix

Add the missing `]#`. If you meant a single-line comment that starts with `[`, put a space after the `#`:

```lymra
# [1] see below
```
