# L0115: source file is not valid UTF-8

The file contains bytes that are not valid UTF-8, so it cannot be read as text.

## Example

A file saved in an older encoding such as Latin-1 or Windows-1252, with an accented letter in a comment or in text:

```lymra
# caf\xE9  (the byte E9 alone is not valid UTF-8)
```

## Why

Lymra source files are UTF-8 (spec 2.1). One encoding for every file means text in a program reads the same on every machine, and the compiler never has to guess.

## Fix

Save the file as UTF-8. Every modern editor can do this, usually under "Save with encoding". The message gives the line of the first invalid byte.
