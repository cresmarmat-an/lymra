# L0102: tabs and spaces mixed in indentation

A file indents with tabs or with spaces, never both. This line used the other kind, or both at once.

## Example

```lymra
function main()
    print("indented with four spaces")
	print("indented with one tab")
```

## Why

Indentation decides which block a line belongs to. A tab has no fixed width, so a line with a tab can look aligned in one editor and misaligned in another. If the compiler guessed a width, the same file could mean two different programs. Lymra refuses to guess.

The first indented line in a file decides which kind the whole file uses.

## Fix

Indent the line the same way as the rest of the file. Most editors can convert a whole file between tabs and spaces in one step.
