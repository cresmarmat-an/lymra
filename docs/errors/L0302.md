# L0302: code at the wrong level

A statement appears at the top level of a file, or a declaration appears inside a function.

## Example

```lymra
print("this runs when?")

function main()
    function helper()
        print("nested")
```

## Why

The top level of a file holds only declarations: `use`, `constant`, `function`, `type` and `choice`. A program starts in `function main()`, so the order in which things run is never in doubt. If statements could sit between declarations, startup order would depend on file order and import order.

Declarations cannot be nested inside functions. A function is found at the top level of its file, never hidden inside another one.

## Fix

Move statements into a function, and move declarations to the top level.

```lymra
function helper()
    print("not nested")

function main()
    print("this runs first")
    helper()
```
