# L0503: `return` does not match the function

A `return` gives a value in a function that returns nothing, or gives no value in a function declared with `returns`.

## Example

```lymra
function greet()
    print("hello")
    return 1

function main()
    greet()
```

## Why

The declaration says what a function gives back, and a caller relies on it. Every `return` has to agree with it, so the declaration is always the whole truth.

## Fix

Remove the value, or declare the return type with `returns`.

```lymra
function greet()
    print("hello")
    return

function main()
    greet()
```
