# L0502: function can end without returning a value

A function declared with `returns` has a path through it that reaches its end without a `return`.

## Example

```lymra
function sign(integer64 number) returns integer64
    if number > 0
        return 1
    else if number < 0
        return -1

function main()
    print("{sign(5)}")
```

## Why

If control reached the end, the function would have no value to give back. In C that is undefined behavior: the caller gets whatever happens to be in a register. Lymra checks every path instead. An `if` without an `else` can always be skipped, and a `while` loop can stop unless its condition is `true` and nothing breaks out of it.

## Fix

End every path with `return` and a value.

```lymra
function sign(integer64 number) returns integer64
    if number > 0
        return 1
    else if number < 0
        return -1
    return 0

function main()
    print("{sign(5)}")
```
