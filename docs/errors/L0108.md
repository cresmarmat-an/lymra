# L0108: unexpected character

The source contains a character that Lymra does not use in that position.

## Example

```lymra
constant price = $100
constant café = "open"
```

## Why

There are three common causes:

- A symbol with no meaning in Lymra, such as `$`, `@`, `?` or a backtick.
- A name with a letter outside ASCII. Names use only `a-z`, `A-Z`, `0-9` and `_`, so that two names that look the same are always the same name. Text and comments can contain any character.
- An invisible character, such as a no-break space pasted from a web page. It looks like a space but is a different character.

## Fix

Remove the character, or replace it as the message suggests. For an invisible character, delete it and type a normal space.

```lymra
constant price = 100
constant cafe = "open"
```
