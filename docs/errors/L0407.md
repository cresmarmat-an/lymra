# L0407: new text in an element of a list

An element of a list or a stack whose elements hold text can't get new text in place. Its other parts can change: a number in it, or a `boolean`.

## Example

```lymra
function main()
    variable list[string] names = list()
    push(variable names, "Ana")
    push(variable names, "Bo")
    names[0] = "Cy"
    print("{names[0]} {names[1]}")
```

## Why

A list keeps the text of its elements on a data stack of its own, one element's text after another, in the order of the elements. That order is what lets a list grow, move to where a function's caller wants it, or give back its top element with `pop`, without a garbage collector and without searching for free space. New text for one element would have to go after the text of the last element, out of order, and the old text would stay behind until the whole list is freed: a loop that renamed one element a million times would keep a million old names.

## Fix

Build the list again with the element changed, then replace the old one. The list frees the old text in one step when it is replaced:

```lymra
function main()
    variable list[string] names = list()
    push(variable names, "Ana")
    push(variable names, "Bo")
    variable list[string] renamed = list()
    for index in range(0, length(names))
        if index == 0
            push(variable renamed, "Cy")
        else
            push(variable renamed, names[index])
    names = renamed
    print("{names[0]} {names[1]}")
```
