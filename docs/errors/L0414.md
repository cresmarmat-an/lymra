# L0414: field not given once by name

A construction such as `Frog(name = "Kero", age = 3)` gives every field of the type exactly once, by name, in any order. This one leaves a field out, gives one twice, or gives a value without saying which field it is for.

## Example

```lymra
type Frog
    string name
    unsigned8 age

function main()
    constant frog = Frog(name = "Kero")
    print("{frog.name}")
```

## Why

A value of a declared type holds all its fields from the moment it exists, so no field is ever read before something was put there. Lymra has no default values that would fill a field in silently. Naming each field keeps a construction readable when fields share a type: `Point(x = 1, y = 2)` cannot be mixed up the way `Point(1, 2)` can.

## Fix

Give every field once, with its name.

```lymra
type Frog
    string name
    unsigned8 age

function main()
    constant frog = Frog(name = "Kero", age = 3)
    print("{frog.name} is {frog.age}")
```
