# L0107: inconsistent indentation depth

A line is indented by an amount that does not fit the file. Either the number of spaces is not a multiple of the file's indent width, or the line is more than one level deeper than the line that opens its block.

## Example

```lymra
function main()
    print("the first indented line sets the width: four spaces")
      print("six spaces is between two levels")
            print("twelve spaces is two levels deeper")
```

## Why

The first indented line in a file sets the width of one level, and every later line is measured against it. A line between two levels belongs to neither block, so the compiler cannot know which one you meant.

A block is exactly one level deeper than the line that opens it. Two levels at once would leave a level with no line to own it.

## Fix

Indent each block by one level, using the same width everywhere in the file.

```lymra
function main()
    print("four spaces")
    print("four spaces")
```
