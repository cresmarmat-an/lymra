# L0505: value is not used

A statement computes a value and then drops it: a call to a function that returns a value, or an expression that does nothing.

## Example

```lymra
function square(integer64 number) returns integer64
    return number * number

function main()
    square(4)
```

## Why

Calling a function for its result and then ignoring the result is almost always a mistake. A statement that only computes a value does nothing at all, and the usual cause is a slip like `count == 5` where `count = 5` was meant.

When a value really is not needed, drop it on purpose: `constant _ = square(4)`.

## Fix

Use the value.

```lymra
function square(integer64 number) returns integer64
    return number * number

function main()
    print("{square(4)}")
```
