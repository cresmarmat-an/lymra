# L0206: unknown name

An expression uses a name that nothing declares where it is used.

## Example

```lymra
function main()
    constant count = 3
    print("{cuont}")
```

## Why

Every name is resolved when the program is compiled, so a misspelled name can never reach the running program. A local binding is visible from its declaration to the end of its block. A top-level constant or function is visible everywhere in its file.

`_` is never visible: it names a value that is thrown away.

When a visible name is spelled almost the same, the error suggests it.

## Fix

Fix the spelling, or declare the name before the line that uses it.

```lymra
function main()
    constant count = 3
    print("{count}")
```
