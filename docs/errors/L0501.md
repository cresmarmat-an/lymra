# L0501: wrong number of arguments

A call gives a function more or fewer arguments than it has parameters.

## Example

```lymra
function area(integer64 width, integer64 height) returns integer64
    return width * height

function main()
    print("{area(3)}")
```

## Why

Lymra has no default values for parameters and no functions that share a name, so every call passes exactly one value for each parameter, in order. A call then always means the same function, and nothing is filled in behind your back.

## Fix

Pass one argument for each parameter.

```lymra
function area(integer64 width, integer64 height) returns integer64
    return width * height

function main()
    print("{area(3, 4)}")
```
