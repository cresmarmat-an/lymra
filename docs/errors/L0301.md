# L0301: unexpected token

The parser found something other than what the grammar allows at that point. The message says what it expected and what it found.

## Example

```lymra
function main()
    print("unclosed"
    total = 1 +
    if ready = true
        go()
```

## Why

This is the general syntax error. Common causes:

- A bracket that is never closed. The message points at the bracket that is still open.
- An operator with nothing after it.
- `=` in a condition, where `==` was meant.
- Two statements on one line.
- A keyword used as a name.
- A misspelled keyword. The message suggests the nearest one.

## Fix

Read the "expected" part of the message. It names exactly what has to appear at the marked position.

```lymra
function main()
    print("closed")
    total = 1 + 2
    if ready == true
        go()
```
