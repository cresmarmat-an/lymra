# L0804: `main` failing with something other than text

`main` can be declared with `fails string`. When it fails, the program writes `error: ` and the text to standard error and exits with status 1. No other type can stand after `fails` on `main`.

## Example

```lymra
choice SetupError
    NoName

function main() fails SetupError
    fail NoName
```

## Why

Nothing calls `main` but the system, which can only show text and take an exit status. A choice or a number has no wording of its own, so the program could only print a variant's name, which helps the person who wrote the program and nobody who runs it. Text says what went wrong in words the person running the program understands.

## Fix

Fail with the text the person running the program should read:

```lymra
function main() fails string
    fail "no name was given"
```

Turn another function's failure into text where it is passed on, with `try call else fail value`:

```lymra
choice SetupError
    NoName

function name_of(string given) returns string fails SetupError
    if length(given) == 0
        fail NoName
    return given

function main() fails string
    constant name = try name_of("Ana") else fail "no name was given"
    print("hello {name}")
```
