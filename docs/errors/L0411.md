# L0411: index out of range

An index known while compiling falls outside its array. An array of length `n` has elements at the indexes `0` to `n - 1`.

## Example

```lymra
function main()
    variable array[integer64, 3] scores = array(0)
    scores[3] = 7
    print("{scores[0]}")
```

## Why

Every index is checked: one that falls outside its array stops the program with a runtime error instead of reading or changing other memory. When the index is known while compiling, the check would fail every time the line runs, so the compiler reports it now. Indexes start at 0, so the last element of a 3-element array is at index 2, and there are no negative indexes counting back from the end.

## Fix

Index from 0 up to the length, without the length itself. The last element is at `length(scores) - 1`.

```lymra
function main()
    variable array[integer64, 3] scores = array(0)
    scores[2] = 7
    print("{scores[length(scores) - 1]}")
```
