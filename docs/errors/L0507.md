# L0507: function and value confused

A function or a type is used as a value, or something other than a function is called: a value, or a type that nothing converts to, `boolean` or `string`. Calling an integer type, as in `integer32(count)`, is a conversion and is fine.

## Example

```lymra
function answer() returns integer64
    return 42

function main()
    constant result = answer
    print("{result}")
```

## Why

Functions are not values in Lymra. There are no function pointers (spec section 7.5), so every call goes to a function the compiler knows, and it can be inlined. A name is either a function, which is called with `(...)`, or a value, which cannot be called.

## Fix

Call the function to use its result.

```lymra
function answer() returns integer64
    return 42

function main()
    constant result = answer()
    print("{result}")
```
