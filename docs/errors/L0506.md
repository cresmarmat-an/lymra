# L0506: missing or malformed `main`

A program has no `function main()`, or its `main` takes or returns something the system cannot give it or take back. A file without `main` can be checked, but it cannot be built or run.

## Example

```lymra
function main(integer64 count)
    print("{count}")
```

## Why

The system starts a program with a list of text, the command line, and takes one small number back when it ends, the exit status. So `main` takes nothing, or the arguments as a `view[string]`, and returns nothing, which exits with status 0, or an `unsigned8`, the exit status itself. It can also fail with text (Section 8). A number the program needs at the start comes from the arguments, as text the program reads.

## Fix

Take the arguments and read the number from them:

```lymra
function main(view[string] arguments) returns unsigned8
    if length(arguments) != 1
        print("give one number")
        return 64
    print("{arguments[0]}")
    return 0
```

Or keep the value inside `main`:

```lymra
function main()
    constant integer64 count = 3
    print("{count}")
```
