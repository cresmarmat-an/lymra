# L0506: missing or malformed `main`

A program has no `function main()`, or its `main` takes parameters or returns a value. A file without `main` can be checked, but it cannot be built or run.

## Example

```lymra
function main(integer64 count)
    print("{count}")
```

## Why

A program starts in `function main()`. In edition 0.1 it takes nothing and returns nothing: there is no way to read the command line yet, and a program exits with status 0 unless it stops on a runtime error.

## Fix

Declare `main` without parameters or a return type, and keep the value inside it.

```lymra
function main()
    constant integer64 count = 3
    print("{count}")
```
