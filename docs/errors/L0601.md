# L0601: `break` or `continue` outside a loop

`break` or `continue` appears where no `while` or `for` loop encloses it.

## Example

```lymra
function main()
    constant count = 3
    if count > 2
        break
    print("done")
```

## Why

`break` leaves the innermost loop, and `continue` starts its next round. Outside a loop there is nothing for them to act on.

## Fix

To leave the function early, use `return`.

```lymra
function main()
    constant count = 3
    if count > 2
        return
    print("done")
```
