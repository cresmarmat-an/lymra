# L0805: `try` with `else fail` inside an expression

`try call else fail value` is the whole value of its statement: a declaration, an assignment, a `return`, or a statement of its own.

## Example

```lymra
choice DigitError
    NotADigit

function digit(string text) returns integer64 fails DigitError
    constant shown = bytes(text)
    if length(text) != 1 or shown[0] < 48 or shown[0] > 57
        fail NotADigit
    return integer64(shown[0] - 48)

function main() fails string
    constant total = 1 + try digit("7") else fail "7 is not a digit"
    print("{total}")
```

## Why

The value after `fail` runs to the end of the expression, so inside a larger one a reader could not tell where it stops: here it could be `"7 is not a digit"`, or the sum of everything after `fail`. On a line of its own, `try` with `else fail` has exactly one reading.

## Fix

Give the `try` its own statement, and use its value in the next one:

```lymra
choice DigitError
    NotADigit

function digit(string text) returns integer64 fails DigitError
    constant shown = bytes(text)
    if length(text) != 1 or shown[0] < 48 or shown[0] > 57
        fail NotADigit
    return integer64(shown[0] - 48)

function main() fails string
    constant value = try digit("7") else fail "7 is not a digit"
    constant total = 1 + value
    print("{total}")
```
