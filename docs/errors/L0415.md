# L0415: type contains itself

A type holds one of its own kind in a field, directly or through other types or arrays. A value of it would contain another, which would contain another, without end.

## Example

```lymra
type Node
    integer64 label
    Node next

function main()
    print("nodes")
```

## Why

A value is stored as one block, with its fields inline (Section 4.5). That makes values fast to read, copy and free. A type that contains itself would need a block without end. Languages that allow it, such as C and Rust, put a pointer or a `Box` in the field, and with it the allocation and the pointer chasing that Lymra avoids.

## Fix

Keep the values in an array, and let a field hold the index of another one.

```lymra
type Node
    integer64 label
    integer64 next

function main()
    variable array[Node, 4] nodes = array(Node(label = 0, next = -1))
    nodes[0] = Node(label = 1, next = 1)
    nodes[1] = Node(label = 2, next = -1)
    variable integer64 at = 0
    while at != -1
        print("{nodes[at].label}")
        at = nodes[at].next
```
