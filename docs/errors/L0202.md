# L0202: binding that is never used

A binding is declared and never read. This covers local `constant` and `variable` bindings, parameters, loop variables and private top-level constants.

## Example

```lymra
function main()
    constant unused = 42
    print("hello")
```

## Why

An unused binding is leftover code, or a mistake: a value computed and then forgotten, or a name misspelled where it should have been used. A variable that is assigned but never read is the same mistake.

Some values are needed only for what computing them does. Discard them on purpose with the name `_`, which is never reported: `constant _ = save_file()`. A parameter that a function has to take but does not use can also be named `_`, and so can a loop variable when the loop only repeats.

## Fix

Use the binding, or remove it.

```lymra
function main()
    constant answer = 42
    print("the answer is {answer}")
```
