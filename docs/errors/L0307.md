# L0307: misplaced `with` block

A `with` block does not directly follow a call.

## Example

```lymra
function main()
    constant total = 1 + sum(numbers) with n
        n * 2
```

## Why

A `with` block is an argument: a piece of code handed to one call (spec 7.7). It belongs to the call written right before it, and that call has to be the whole expression of the statement. In `1 + sum(numbers) with n`, a reader could not tell whether the block goes to `sum` or to the whole sum.

## Fix

Give the block to a call that stands alone, and use the result on another line.

```lymra
function main()
    constant doubled = sum(numbers) with n
        n * 2
    constant total = 1 + doubled
```
