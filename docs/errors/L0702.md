# L0702: stack popped while something still uses it

A stack cannot be popped while something still reads its elements: a `for` loop that goes over it, or a view of it that is used later. Popping frees the top element.

## Example

```lymra
function main()
    variable stack[integer64] work = stack()
    push(variable work, 1)
    push(variable work, 2)
    for item in work
        constant done = pop(variable work)
        print("{item} {done}")
```

## Why

`for item in work` reads one element of `work` each time around, from where the stack keeps them, and it goes over the elements the stack held when the loop started. The first turn pops `2`, so the second turn would read the slot `2` was taken from: memory the stack no longer holds, which the next `push` builds over. C++ lets this happen with `std::vector` and calls it undefined behavior; Java stops the program while it runs. Lymra rejects it before the program exists.

A function that gets the stack with `variable` and can pop it, itself or through the functions it calls, makes the same mistake when it is called inside the loop; one that only pushes is fine. Changing an element, or adding one with `push`, is fine too: elements never move, and the loop never reads past the elements it started with.

A view is the same: `constant waiting = slice(work, 0, 2)` shows elements of `work`, so `work` cannot be popped while `waiting` is still used after that point. The compiler follows where every view is used, so popping after the last use of the stack's views is fine.

## Fix

To take each element off in turn, loop while the stack has elements and pop inside the loop. Each turn gets the top element as a value of its own:

```lymra
function main()
    variable stack[integer64] work = stack()
    push(variable work, 1)
    push(variable work, 2)
    while length(work) > 0
        constant item = pop(variable work)
        print("{item}")
```

If the loop has to see every element first, finish it, and pop after it ends. A view works the same way: finish with it before the pop, or copy what it shows into a list of its own.
