# L0403: unknown type

A type name is not one of the types Lymra has.

## Example

```lymra
function main()
    constant integer count = 3
    print("{count}")
```

## Why

The types available now are `integer8`, `integer16`, `integer32` and `integer64`, `unsigned8` to `unsigned64`, `boolean`, and `string`. Every integer type states its size in bits, so there is no plain `integer`: the size of a number is never left to the platform.

## Fix

Use one of the types, with its size.

```lymra
function main()
    constant integer64 count = 3
    print("{count}")
```
