# L0207: name declared twice

A declaration uses a name that is already declared where the new one would be visible. Built-in function names, `print` and `range`, are taken as well.

## Example

```lymra
constant limit = 10

function main()
    constant limit = 20
    print("{limit}")
```

## Why

In many languages the inner `limit` would hide the outer one. Which `limit` a line means then depends on where the line is, and moving a line can change what it does without changing its text. Lymra has no hiding: wherever a name is visible, it means one thing.

Two blocks side by side may each declare the same name, because neither can see the other.

## Fix

Give the new binding its own name.

```lymra
constant limit = 10

function main()
    constant local_limit = 20
    print("{limit} {local_limit}")
```
