# L0209: variable that never changes

A binding or a parameter is declared `variable`, but nothing ever changes it.

## Example

```lymra
function main()
    variable greeting = "hello"
    print(greeting)
```

## Why

`variable` tells a reader to watch for changes. When nothing changes the binding, the word is misleading, and it often means an intended change is missing. A `variable` parameter that the function never changes also forces every caller to mark its argument for nothing.

## Fix

Declare it with `constant`. For a parameter, remove `variable`.

```lymra
function main()
    constant greeting = "hello"
    print(greeting)
```
