# L0413: unknown field

A construction or a `.` names a field that the type does not have. A value of a type declared with `type` has exactly the fields its declaration lists, and other values have no fields at all.

## Example

```lymra
type Frog
    string name
    unsigned8 age

function main()
    constant frog = Frog(name = "Kero", age = 3)
    print("{frog.nam} is {frog.age}")
```

## Why

The declaration fixes a type's fields, so the compiler knows where each one sits inside the value, and the program never looks a field up while it runs. A field the declaration does not list can only be a mistake, most often a misspelling, and the error suggests the closest field.

## Fix

Use a field the declaration lists.

```lymra
type Frog
    string name
    unsigned8 age

function main()
    constant frog = Frog(name = "Kero", age = 3)
    print("{frog.name} is {frog.age}")
```
