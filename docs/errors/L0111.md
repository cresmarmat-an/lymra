# L0111: text is never closed

A text literal, or an interpolation inside one, reaches the end of the line without being closed.

## Example

```lymra
function main()
    print("Hello, world)
    print("Hello, {name")
```

## Why

Text has to start and end on the same line. If it could run on, one missing quote would turn the rest of the file into text and the error would show up far from the mistake.

Inside text, `{` starts an interpolation, which needs its closing `}` before the text ends.

## Fix

Add the closing `"` or `}`. To put a line break inside text, write `\n`. To write a literal brace, double it:

```lymra
function main()
    print("Hello, world")
    print("first line\nsecond line")
    print("a literal {{brace}}")
```
