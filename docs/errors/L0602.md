# L0602: unreachable code

A statement comes after a `return`, `break` or `continue`, or after an `if` whose branches all leave, so it can never run.

## Example

```lymra
function main()
    print("start")
    return
    print("never printed")
```

## Why

Code that can never run is either left over from an edit, or a sign that the program does not flow the way its author thinks. Either way, a reader should not have to find out by tracing it.

## Fix

Remove the unreachable code, or move it before the line that leaves.

```lymra
function main()
    print("start")
    print("printed now")
    return
```
