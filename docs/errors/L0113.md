# L0113: malformed interpolation

The braces in a text literal do not form a valid interpolation: a `}` has no `{` before it, or the braces are empty.

## Example

```lymra
function main()
    print("score: {}")
    print("a closing } brace")
```

## Why

Inside text, `{expression}` inserts the value of the expression. A `}` with no interpolation open, or a pair of braces with nothing between them, is almost always a typo, so it is rejected instead of printed as written.

## Fix

Put an expression between the braces. To print a literal brace, double it.

```lymra
function main()
    print("score: {score}")
    print("a closing }} brace")
```
