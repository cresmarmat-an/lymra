# L0306: chained comparison

Two comparisons are written in a row, as in `a < b < c`.

## Example

```lymra
function main()
    if 0 <= index < length
        print("in range")
```

## Why

In mathematics, `0 <= index < length` means both comparisons hold. In C it means something else: `0 <= index` is computed first, and its result, true or false, is then compared with `length`. That compiles and is almost always wrong.

Lymra accepts neither reading. Rejecting the chain means the code can only say what it means.

## Fix

Write each comparison separately and join them with `and`.

```lymra
function main()
    if 0 <= index and index < length
        print("in range")
```
