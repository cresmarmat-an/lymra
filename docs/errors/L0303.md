# L0303: missing indented block

A line that opens a block is not followed by an indented line.

## Example

```lymra
function main()
print("not indented")
```

## Why

Blocks are defined by indentation (spec 2.4). The lines that belong to a `function`, `if`, `while`, `for`, `match`, `case`, `type` or `choice` are the lines below it that are indented one level deeper. With no indented line, the block is empty, and an empty block is always a mistake.

## Fix

Indent the lines of the block one level. A function that should do nothing yet can hold a single `return`.

```lymra
function main()
    print("indented")

function not_written_yet()
    return
```
