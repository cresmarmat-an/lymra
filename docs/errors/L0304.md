# L0304: unexpected indentation

A line is indented deeper than the line above it, but the line above does not open a block.

## Example

```lymra
function main()
    print("one")
        print("why is this deeper?")
```

## Why

Indentation has meaning: a deeper line belongs to a block opened by the line above. If no block was opened, the extra indentation says something that is not true about the structure of the code.

## Fix

Indent the line like the one above it. If it was meant to be inside a block, add the line that opens the block.

```lymra
function main()
    print("one")
    print("same level")
```
