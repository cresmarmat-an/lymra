# L0801: failure the function cannot fail with

`fail` and `try` end a function with a failure, so the function has to be declared with `fails` and the type of that failure. A `try` passes the failure of its call on as it is, so the two functions have to fail with the same type.

## Example

```lymra
choice DigitError
    Empty
    NotADigit

function digit(string text) returns integer64 fails DigitError
    if length(text) == 0
        fail Empty
    constant shown = bytes(text)
    if shown[0] < 48 or shown[0] > 57
        fail NotADigit
    return integer64(shown[0] - 48)

function main()
    print("{try digit("7")}")
```

## Why

A declaration with `fails` tells every caller that a call can end with a failure, and the compiler makes each caller deal with it. `try` deals with it by ending the function it is in with that same failure, which only works if that function's declaration says it can fail, and with that type: a reader of `main` would otherwise never learn that it can stop early. A failure never turns into another type by itself, for the same reason a number never does (Section 4.1): the code that receives it would be wrong about what it holds.

## Fix

Handle both cases where the call is made:

```lymra
choice DigitError
    Empty
    NotADigit

function digit(string text) returns integer64 fails DigitError
    if length(text) == 0
        fail Empty
    constant shown = bytes(text)
    if shown[0] < 48 or shown[0] > 57
        fail NotADigit
    return integer64(shown[0] - 48)

function main()
    match digit("7")
        case Success(value)
            print("{value}")
        case Failure(error)
            match error
                case Empty
                    print("no digit")
                case NotADigit
                    print("not a digit")
```

Or let the function fail too, with a failure of its own type. `main` can fail with text, which the program writes after `error: `:

```lymra
choice DigitError
    Empty
    NotADigit

function digit(string text) returns integer64 fails DigitError
    if length(text) == 0
        fail Empty
    constant shown = bytes(text)
    if shown[0] < 48 or shown[0] > 57
        fail NotADigit
    return integer64(shown[0] - 48)

function main() fails string
    constant value = try digit("7") else fail "7 is not a digit"
    print("{value}")
```
