# L0104: index not proven in range

A file that starts with `#!prove bounds` asks the compiler to prove that every index stays inside its array or list. This index could not be proven: the error says which values the compiler knows the index can have at that point.

## Example

```lymra
#!prove bounds

function main()
    variable array[integer64, 4] values = array(0)
    values[2] = 7
    variable integer64 position = 0
    while values[position] != 7
        position = position + 1
    print("{position}")
```

## Why

Every index is checked when the program runs, and the compiler removes the checks it can prove unnecessary. `#!prove bounds` turns that into a promise: the file compiles only if no check is left, so a hot loop gets code without checks and keeps its safety. Languages that let you switch checks off instead trust the programmer, and a wrong guess reads or writes memory it should not.

The compiler learns about a value from the bounds of `for` loops over `range`, the conditions of `if`, `while` and `assert`, the left side of `and` and `or`, and known values. It follows each variable through a loop, and a parameter holds the values that the program's calls pass to it. A value read from an array can be any value of its type.

A list's length is only known when the program runs, so an index into a list is proven by its tie to the length: `for index in range(0, length(items))`, or a test such as `index < length(items)` or `index + 1 < length(items)`. The tie holds until the index changes or the list is replaced or passed with `variable`; `push` only makes a list longer, so it keeps the tie.

Here nothing stops the search at the end of the array. It finds the 7 this time, but a search for a value the array does not hold would run past its end.

## Fix

Check the index where the compiler can see it: in the loop's condition, with an `if`, or with an `assert` before the loop. The right side of `and` runs only when the left side is true, so it knows the index is in range.

```lymra
#!prove bounds

function main()
    variable array[integer64, 4] values = array(0)
    values[2] = 7
    variable integer64 position = 0
    while position < length(values) and values[position] != 7
        position = position + 1
    print("{position}")
```
